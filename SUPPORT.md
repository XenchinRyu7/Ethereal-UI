## 🐛 Reporting Bugs

If you encounter a bug, broken dark-mode contrast, TypeScript type mismatch, or accessibility issue:

1. Search existing [GitHub Issues](https://github.com/XenchinRyu7/Ethereal-UI/issues) to check if it has already been reported.
2. Open a new issue at **[github.com/XenchinRyu7/Ethereal-UI/issues/new](https://github.com/XenchinRyu7/Ethereal-UI/issues/new)** and include:
   - **Package version** (e.g., `@etherealui/react@0.0.1`)
   - **Framework & environment** (e.g., Next.js 15, Astro 5, Vite + React 19, Tailwind CSS v4)
   - **Minimal reproduction steps** or code snippet
   - **Expected vs. actual behavior** (screenshots in Light/Dark mode are highly appreciated!)

## 💡 Feature Requests & Component Proposals

Want to propose a new primitive, statistical chart, or enterprise SaaS block?

- Open a **Feature Request** in [GitHub Issues](https://github.com/XenchinRyu7/Ethereal-UI/issues) or start a thread in **GitHub Discussions**.
- Describe the enterprise use case, required props/variants, and accessibility considerations.
