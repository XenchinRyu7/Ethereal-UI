# Ethereal UI v1.0.0 Official Release

Production-ready major release of **Ethereal UI** (`@etherealui/react` & `@etherealui/cli`):

- **New Primitives**: Added `PasswordInput`, `TagInput`, `FormField`, `Collapsible`, `HoverCard`, `SegmentedControl`, `Card`, `Kbd`, `Rating`, `Spinner`, `CopyButton`, and `AspectRatio`.
- **Advanced Complex Charts Suite**: Added interactive `CandlestickChart` with multi-timeframe switching (1D, 1W, 1M, 1Y) & crosshair, `DepthChart` (order book bid/ask), `RadarChart`, `FunnelChart`, `GaugeChart`, and `TreemapChart`.
- **Enterprise Blocks**: Added `LoginFormBlock`, `PromptComposerBlock`, interactive live-editable `Drawer`, enhanced `ColorPicker` with semantic color rules & custom RGB/HSL spectrum picker.
- **High-Contrast Theming**: Enhanced crisp border lines across all input components (`Input`, `PasswordInput`, `Select`, `Checkbox`, buttons) for light & dark themes.
- **Standalone Community Hub & OSS Contribution System**: Comprehensive guidelines, branching rules, Monorepo Turborepo workflows, and maintainer contacts.
