# `@etherealui/cli`

Official CLI for **Ethereal UI (`@etherealui/react`)** — scaffold accessible React 19 primitives, statistical SVG charts, and enterprise dashboard blocks directly into your project.

---

## 🚀 Usage

### 1. Initialize Configuration & `cn` Helper
```bash
npx @etherealui/cli@latest init
```

### 2. Add Components, Charts, or Enterprise Blocks
```bash
npx @etherealui/cli@latest add avatar button stat-card
npx @etherealui/cli@latest add area-chart data-table --overwrite
```

### 3. List All 56+ Registry Items
```bash
npx @etherealui/cli@latest list
```
