# @etherealui/react

## 0.0.2

### Patch Changes

- 66d1fd2: Initial public release (`v0.0.1`) of **Ethereal UI (`@etherealui/react`)**:

  - **37 Accessible Base Primitives**: Built with React 19, Tailwind CSS v4 native CSS tokens, CVA, and Radix UI Primitives (`Accordion`, `Announcement`, `Avatar`, `Badge`, `Breadcrumb`, `Button`, `ButtonGroup`, `Carousel`, `Checkbox`, `Chip`, `CloseButton`, `ColorPicker`, `Combobox`, `CommandPalette`, `ContextMenuBox`, `DateCalendar`, `DateRangePicker`, `Dialog`, `Divider`, `Drawer`, `DropdownMenu`, `FileDropzone`, `IconButton`, `Input`, `Modal`, `Pagination`, `Popover`, `Progress`, `RadioGroup`, `Select`, `Skeleton`, `Slider`, `Switch`, `Table`, `Tabs`, `Textarea`, `ToastCard`, `Tooltip`).
  - **6 Statistical SVG Chart Primitives**: `AreaStatisticChart`, `BarStatisticChart`, `LineStatisticChart`, `DonutStatisticChart`, `RadialStatisticChart`, and `HeatmapStatisticChart`.
  - **10 Enterprise Dashboard Blocks**: `AppShell`, `SidebarShell`, `HeaderNavbar`, `PageHeaderBar`, `StatCard` (`StatMetricCard`), `ProgressMetricCard`, `MultiMetricGrid`, `EnterpriseDataTable`, `AdvancedFilterBar`, `UserProfileFormBlock`, `TeamRbacTableBlock`, `SecurityPasswordFormBlock`, and `BillingPlanCardBlock`.
  - **3 Full-Page SaaS Templates**: `ExecutiveAnalyticsTemplate`, `ControlTowerTemplate`, and `WorkspaceSettingsTemplate`.
  - **Seamless Light & Dark Mode**: Semantic token architecture with zero legacy `tailwind.config.js` overhead.
