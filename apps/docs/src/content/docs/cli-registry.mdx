## Live JSON Registry Endpoints

Every primitive, enterprise block, and full-page dashboard template in Ethereal UI is automatically indexed and served as a static JSON endpoint during the Astro build:

- **Master Registry Index**: [`/registry/index.json`](/registry/index.json)
- **Individual Item Payload**: `/registry/[slug].json` (e.g. [`/registry/data-table.json`](/registry/data-table.json), [`/registry/executive-analytics.json`](/registry/executive-analytics.json))

---
