## Apa Itu Ethereal UI?

**Ethereal UI (`@etherealui/react`)** adalah open-source, dark-mode first enterprise UI component library dan dashboard system yang dibangun khusus untuk **React 18 & 19**, **Tailwind CSS v4**, dan **Radix UI Primitives**.

Berbeda dari UI kit komersial yang mengunci komponen enterprise berbobot data (seperti server-side data table, multi-metric KPI sparklines, collapsible app shells, AI reasoning streams, dan RBAC settings matrix) di balik **paywall $299+**, setiap primitive, chart, block, dan full-page template di Ethereal UI **100% gratis dan berlisensi MIT selamanya**.

---

## Mengapa Ethereal UI?

Banyak tim developer modern mengalami dilema yang sama saat membangun aplikasi web SaaS atau internal dashboard:

1. **Paywall Komponen Kompleks**: Komponen dasar gratis (button, badge, input), tapi begitu butuh *interactive filter bar*, *kanban board*, *AI prompt composer*, atau *data table*, harus berlangganan lisensi mahal per-developer.
2. **Kerapuhan Kontras Warna di AI Agent**: Ketika AI coding assistant (Cursor, Copilot, Claude) diminta membuat dark mode, sering terjadi bug *"Ghost Field"* — background gelap dengan text hitam, atau background putih dengan text putih.
3. **Migrasi Lambat ke Tailwind CSS v4**: Banyak library masih terjebak di konfigurasi jadul `tailwind.config.js` berbasis JavaScript runtime lama dan tidak memanfaatkan performa engine Rust/LightningCSS milik Tailwind v4.

Ethereal UI hadir untuk menyelesaikan ketiga masalah tersebut secara tuntas.

## Pilar Arsitektur

Ethereal UI dibangun di atas 4 pilar utama:

### 1. Radix UI Primitives & WCAG 2.1 AA
Aksesibilitas bukan sekadar fitur tambahan. Seluruh interaksi keyboard navigation, screen reader announcements, ARIA focus management, dan modal trapping ditangani langsung oleh Radix UI tanpa kompromi.

### 2. Tailwind CSS v4 Native (@theme)
Zero runtime JavaScript overhead untuk styling. Ethereal UI menggunakan native CSS variables dengan directive `@theme inline`, memungkinkan kompiler Tailwind v4 memproses styling dengan kecepatan sub-millisecond.

### 3. Arsitektur Warna OKLCH & Safeguards Kontras
Dengan mengadopsi ruang warna *OKLCH (Oklab Lightness & Chroma)*, persepsi kecerahan warna konsisten di seluruh spektrum visual. Teks selalu terjamin kontras dan terbaca jelas baik di mode Light maupun Dark.

### 4. Copy & Paste atau NPM Package
Anda memegang kendali penuh atas kode Anda. Gunakan sebagai package NPM standar (`@etherealui/react`), atau salin source code komponen langsung ke project Anda via CLI (`npx @etherealui/cli add <component>`).
