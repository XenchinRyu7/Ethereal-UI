# Security Policy

The **Ethereal UI (`@etherealui/react`)** team takes the security and integrity of our open-source packages and registry endpoints seriously. We appreciate the security research community's efforts in responsibly disclosing vulnerabilities.

---

## 🛡️ Supported Versions

The following versions of `@etherealui/react` are currently supported with security updates:

| Package | Version | Supported |
| :--- | :--- | :---: |
| `@etherealui/react` | `0.0.x` (Latest) | ✅ Yes |

---

## 🚨 Reporting a Vulnerability (Private Disclosure)

**Please do NOT report security vulnerabilities through public GitHub Issues, Discussions, or Pull Requests.**

If you discover a security vulnerability (such as XSS vectors in component rendering, prototype pollution, dependency vulnerabilities, or supply-chain issues), please report it privately via email:

- **Security Contact Email**: **[saefulrohmandevelopers@gmail.com](mailto:saefulrohmandevelopers@gmail.com)**
- **Subject Line**: `[SECURITY] Ethereal UI Vulnerability Report — <Brief Summary>`

### What to Include in Your Report:
1. **Affected Component / File**: Path in `packages/ui` or `apps/docs` and version of `@etherealui/react`.
2. **Vulnerability Type**: e.g., Cross-Site Scripting (XSS), injection, dependency advisory, or build pipeline exposure.
3. **Proof of Concept (PoC)**: Step-by-step instructions or minimal reproduction code to verify the issue.
4. **Potential Impact**: Assessment of how an attacker could exploit the issue in a production application.

---

## ⏱️ Response & Resolution Timeline

When you submit a private security report to `saefulrohmandevelopers@gmail.com`, you can expect:

- **Acknowledgment**: Within **48 hours** of receiving your report.
- **Triage & Assessment**: Within **5 business days**, confirming whether the issue is reproducible and determining severity.
- **Patch & Coordinated Release**: A patch release (`@etherealui/react`) will be prepared, tested, and published to NPM, with full credit given to the reporter (unless anonymity is requested).
